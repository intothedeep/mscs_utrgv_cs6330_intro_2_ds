## 2. 파일 이름과 순서 (File Naming and Ordering)

### 2.1 규칙 충돌

- book.md §3: 장은 `chapters/NN-slug.tex`, 번호는 "파일 정렬 = 읽는 순서"를 위해 붙인다.
- book.md 원칙 12: 강의 노트 장은 `chapters/lecNN-slug.tex`.
- latex.md §13: 요청 없이 파일 이름을 바꾸지 않는다.

같은 book.md 안의 두 문장이 서로 다른 이름을 지시한다. core.md에 따라 로컬에서 해결하지 않고
소유자에게 올린다(Q1). 아래는 이름을 바꾸지 않는 기본안이다.

### 2.2 사실: 이름 변경 없이는 "전체 파일 정렬 = 읽는 순서"가 불가능하다

새 개념 장(덱 7, 9)은 1부(기초)에 들어가야 한다. 그런데 `05-`, `06-` 은 이미 2부(실전)의
과제/프로젝트 장이 차지했다. `07-`, `08-` 로 붙이면 정렬은 01~04, 05~06(2부), 07~08(1부)이
되어 읽는 순서와 어긋난다. `04a-`, `04b-` 같은 끼워 넣기는 덱이 더 올 때마다 문자가 늘어나는
임시방편이라 쓰지 않는다.

### 2.3 권고 (기본안, 이름 변경 없음)

1. **새 강의 장은 `chapters/lecNN-slug.tex`, NN = 덱 번호(두 자리).**
   예: `lec07-qq-normalization.tex`, `lec09-hypothesis-testing.tex`.
   - 이유: 덱 번호는 바뀌지 않는다. 덱 8이 나중에 와도 `lec08` 이 자동으로 07과 09 사이에
     정렬된다. 순번(NN)을 쓰면 중간 덱이 올 때마다 뒤 파일을 전부 다시 번호 매겨야 한다.
   - 원칙 12의 이름과 일치한다.
2. **기존 파일(`00`~`06`, `99`)은 그대로 둔다.**
3. **읽는 순서의 유일한 권위는 `parts/*.tex` 의 `\input` 순서다.** 파일 정렬이 아니다.
   `lec*` 끼리는 파일 정렬 = 강의 순서 = 읽는 순서가 성립한다.
4. **배치:** 새 강의 장은 전부 `parts/part1-foundations.tex`(기초)에, 04 뒤에 덱 번호 순으로 둔다.

   ```
   % part1-foundations.tex
   \input{chapters/01-data-attributes}      % 덱 3
   \input{chapters/02-descriptive-statistics} % 덱 4
   \input{chapters/03-visualization}        % 덱 5
   \input{chapters/04-distributions}        % 덱 6
   \input{chapters/lec07-qq-normalization}  % 덱 7
   \input{chapters/lec09-hypothesis-testing} % 덱 9
   ```
   2부(실전)는 손대지 않는다. PDF의 장 번호는 `\input` 순서로 매겨지므로 가설검정 장은
   "6장"이 되고 과제 1 장은 "7장"으로 밀린다. 본문이 전부 `\Cref` 를 쓰므로 깨지는 참조는 없다
   (손으로 박은 장 번호가 없음을 grep으로 확인할 것: pm의 수용 기준 후보).
5. **라벨:** 장 라벨은 주제 이름으로 짓는다(`ch:hypothesis`, `ch:qq-normalization`).
   파일 이름과 무관하므로 Q1의 결론이 무엇이든 라벨은 바뀌지 않는다.

### 3.1 장 머리 In brief (원칙 12의 1단계)

- **Why:** 표본 하나에서 본 차이가 진짜인지 우연인지 가르는 규칙이 필요하다.
- **When:** "차이가 없다(또는 기존 값 그대로다)"를 기본값으로 두고, 데이터가 그 기본값을 뒤집을 만큼 강한지 물을 때.
- **Where:** 두 약의 회복 시간 비교, 비율(수컷 강아지 비율, 반항적 인간 비율), 성공 확률(복권) 같은 모수(Parameter)에 대한 주장.
- **How:** 귀무가설(Null Hypothesis) $H_0$ 와 대립가설(Alternative Hypothesis) $H_a$ 를 세운다 → 기준 $\alpha$ 를 미리 정한다 → $H_0$ 가 참일 때 관측값 이상으로 극단적인 결과가 나올 확률을 구한다 → 기준보다 작으면 기각(Reject), 아니면 기각 실패(Fail to Reject).

### 3.2 절 구성 (여섯 단계 뼈대 + 무엇 안의 세부 절)

각 개념 절은 원칙 7의 `inbrief` 네 줄로 연다. 아래 한 줄씩이 그 초안이다.

#### (1) 배경 `sec:ht-background` (개념 절 아님, In brief 생략)

선공급할 선행 개념(원칙 9a). 이미 다룬 것은 한 줄 요약 + `\Cref`, 처음인 것은 그 자리에서 두 문장.

| 선행 개념 | 어디서 다뤘나 | 이 장에서의 처리 |
| :-- | :-- | :-- |
| 평균, 퍼짐(표준편차) | `\Cref{sec:center}`, `\Cref{sec:spread}` | 한 줄 요약 + 링크. 3.2 (8)절의 "평균에서의 거리"에 쓴다 |
| 표본(Sample)과 모집단(Population) | `\Cref{sec:skew-compute}` 에서 스치듯 | 두 문장으로 직접 정의. "우리가 보는 것은 표본, 주장하는 것은 모집단" |
| 모수(Parameter) | 없음 | 두 문장으로 정의. 슬라이드 10의 "parameter = value" 를 읽으려면 필요 |
| 확률, 독립 시행의 곱셈 규칙 | 없음 (`sec:binomial` 은 stub) | 두 문장 + 동전 두 번 예. 슬라이드 13의 $0.4^3$ 에 필요 |
| 이항분포(Binomial Distribution) | `\Cref{sec:binomial}` (현재 stub, 4.3절에서 채움) | 한 문단 요약. "$n$ 번 시행 중 성공 횟수". 링크는 stub이어도 컴파일된다 |
| 신뢰구간과 "5% 미만이면 유의" | `\Cref{sec:ci}`, `\Cref{subsec:ci-compare}` | 한 줄 요약 + 링크. 덱 5가 이미 5% 기준과 "p-value < 0.05" 라는 말을 썼다(덱 5 슬라이드 24, 26, 27) |
| 부트스트랩(재표집) | `\Cref{subsec:bootstrap}` | 한 줄. "컴퓨터로 반복해서 분포를 만든다"는 발상이 슬라이드 11~12의 시뮬레이션과 같다 |

용어 주의: 덱 9는 "p-value", "significance level" 이라는 말을 쓰지 않는다("significance test"만
쓴다). 이 장은 덱 9가 계산하는 양(슬라이드 11, 12의 "13 이상일 확률")에 p값(p-value)이라는
이름을 붙이고, 그 이름이 덱 5에서 이미 나왔음을 밝힌다.

기호 표 `tab:ht-symbols` (원칙 9c):

| 기호 | 뜻 | 읽기 |
| :-- | :-- | :-- |
| $H_0$ | 귀무가설(Null Hypothesis): 차이 없음, 기존 값 그대로 | 에이치 제로 |
| $H_a$ | 대립가설(Alternative Hypothesis): 찾으려는 주장 | 에이치 에이 |
| $p$ | **두 가지 뜻이 있다.** (i) 모수로서 성공 확률(슬라이드 11: $p = 50\%$), (ii) p값 | 반드시 경고 상자로 구분 |
| $\alpha$ | 유의수준(Significance Level): 미리 정한 기각 기준(덱 9는 1%, 덱 5는 5%) | 알파 |
| $n$, $X$ | 시행 횟수, 성공 횟수 | |

`pitfall` 하나: 기호 $p$ 가 슬라이드 11에서 "수컷일 확률"(모수)로 쓰이고, 이 장에서는 p값으로도
쓰인다. 모수는 $p$ 대신 $\pi$ 나 $\theta$ 로 바꾸지 말고(슬라이드와 어긋남), 본문에서 p값은 항상
"p값"이라는 한글 단어로 쓰고 모수만 기호 $p$ 로 쓴다.

#### (2) 왜 필요한가 `sec:ht-why` (원칙 8의 문제 → 처방)

- 문제 1(슬라이드 3): 같은 약을 먹어도 회복 시간이 사람마다 다르다. 실험 한 번의 평균 차이
  (A가 B보다 15시간 빠름)는 다시 하면 달라진다.
- 문제 2(슬라이드 4): 다시 해 보니 오히려 A가 35시간 더 느렸다. 한 번의 결과로 세운 가설이
  뒤집힌다. 이 경우는 확신을 갖고 기각한다.
- 문제 3(슬라이드 5): 13시간 가설은 "첫 실험이 13이었다"는 이유 하나로 정해졌다. 재실험(12시간,
  13.5시간)은 기각할 만큼 다르지도, 맞다고 확신시킬 만큼 같지도 않다.
- 처방(슬라이드 8): 예비 자료로 숫자를 정하는 대신, 예비 자료가 필요 없는 유일한 값 **0**(차이 없음)을
  가설로 삼는다. 이것이 귀무가설이다.
- 그림: `fig:ht-drug-experiments` (아래 3.4).

| 두 집단 비교: 평균에서의 거리 | `sec:ht-two-groups` | Why: "차이가 있다"는 두 집단 평균을 따로 둘 때 점들이 평균에 훨씬 가까워진다는 뜻이다. / When: 두 집단의 연속값(회복 시간)을 비교할 때. / Where: 약 C 대 D. / How: 합친 평균 하나(귀무)와 집단별 평균 둘(대립)에서 거리를 재어 비교한다. 줄어든 양이 작으면 기각 실패. | 9 |

`sec:ht-decision` 안의 `pitfall`: "기각 실패는 $H_0$ 가 참이라는 증명이 아니다." 슬라이드 2(금성에서
외계 생명을 못 찾았다고 없다는 뜻은 아니다)와 슬라이드 5("don't convince us the hypothesis is
correct")가 근거. `\Cref{subsec:ci-compare}` 의 함정 "겹친다고 같은 것은 아니다"와 같은 논리임을
명시한다. 표 `tab:ht-wording`(올바른 표현 / 틀린 표현)을 둔다.

`sec:ht-pvalue` 안의 `pitfall`: 기준값 1%(덱 9)와 5%(덱 5, `\Cref{sec:ci}` 의 $1.96$)가 다르다.
기준은 법칙이 아니라 **데이터를 보기 전에 정하는 약속**이다. `\Cref{subsec:fence}` 의 "1.5는
관례다"와 같은 구조의 함정으로 연결한다.

`sec:ht-forms` 안의 `pitfall`: 슬라이드 12의 방향 문제(3.5의 E4 참조). 방향은 데이터를 보고 고르지
않는다.

#### (4) 어떻게 적용하는가 `sec:ht-apply` (장 끝)

- 다섯 단계 절차 상자(= `fig:ht-flow`): 가설 → $\alpha$ → 극단의 정의(방향) → p값(시뮬레이션 또는
  정확 계산) → 문장으로 결론.
- 이 책 안의 적용 자리:
  - `\Cref{subsec:ci-compare}`: 버거(평균 620, CI $[557, 686]$) 대 치킨너겟(평균 275, CI $[211, 345]$).
    같은 질문을 $H_0$: "두 평균 칼로리 차이 = 0" 으로 다시 쓰면 CI 비교가 곧 그림으로 한 가설검정임을 보인다.
    새 수치 계산은 하지 않는다(값은 03에 이미 있다).
  - `\Cref{subsec:bootstrap}`: 재표집으로 분포를 만든다는 발상이 `sec:ht-simulation` 과 같다.
    차이점 한 줄: 부트스트랩은 **표본**에서 뽑고, 가설검정 시뮬레이션은 **$H_0$ 가 정한 세상**에서 뽑는다.
  - `\Cref{ch:hw1}`: 과제 데이터에서 세울 수 있는 $H_0$ 예시 한두 개(계산 없이 가설 문장만).
  - `\Cref{ch:project}`: 프로젝트에서 "차이가 있다"고 쓰기 전에 거칠 점검 목록.
- 확인 문제 3개(슬라이드 14 Kahoot 자리를 대신): 기각/기각 실패 문장 고르기, 방향 고르기, $0.4^n$ 최소 $n$.

#### (5) 앞으로 `sec:ht-future`

- 순열검정(Permutation Test), 통계적 유의성(Statistical Significance), 차등 분석(Differential Analysis):
  강의 계획서(덱 1 슬라이드 3)의 "Statistical Inference" 목록에 있다. 다음 강의로 이어지는 갈래로만 적는다.
- 슬라이드 9의 "평균에서의 거리 비교"를 정식 검정 통계량으로 만드는 방법은 이 덱에 없다. 열린 질문으로 남긴다.
- 복권 예제가 드러낸 질문: $H_0$ 가 틀렸을 때 기각할 수 있는가(표본 크기의 문제). 덱에 없으므로 질문으로만 적는다.
- 외부 문헌은 붙이지 않는다.

### 3.5 예제 (2~3개 + 연습 1개)

- **E1 `ex:ht-puppy`: 강아지 15마리 중 수컷 13마리(슬라이드 11).**
  $H_0$: $p = 0.5$, $H_a$: $p > 0.5$, $\alpha = 1\%$.
  1단계: 표에서 13 이상을 센다(3회) → $0.003$. 2단계: 같은 값을 이항계수로 정확히 구한다
  ($121/32768 = 0.0037$, `align*` 한 줄 한 계산, 원칙 10). 3단계: 두 값이 다른 이유(R4: 표는 반올림된
  기댓값, 14와 15 행이 0으로 반올림됨). 결론: 기각. 문장: "수컷이 더 잘 나온다는 증거가 있다."
- **E2 `ex:ht-juan`: 빨간 셔츠 복권 3연승(슬라이드 13).**
  $H_0$: $p = 0.4$, $H_a$: $p > 0.4$. $0.4^3 = 0.064$ → 기각 실패. 이어서 R10: 3번으로는 결코 기각할 수
  없고, 6연승이어야 1% 밑으로 내려간다. 교훈: 기각 실패는 "셔츠 효과가 없다"가 아니라 "이 표본 크기로는
  말할 수 없다". `\Cref{subsec:notch}` 의 "노치가 뒤집히면 표본이 부족한 것"과 같은 신호.
- **E3 `ex:ht-distance`: 합친 평균 대 집단 평균(슬라이드 9, 책 자체의 예시 값).**
  값은 슬라이드 그림 `image22/23` 모양을 흉내 낸 **책의 예시 값**임을 명시한다:
  C $= \{20, 28, 34\}$, D $= \{22, 26, 37\}$.
  - 합친 평균: $167/6 = 27.83$. 집단 평균: C $82/3 = 27.33$, D $85/3 = 28.33$.
  - 합친 평균에서의 제곱거리 합: $61.36 + 0.03 + 38.03 + 34.03 + 3.36 + 84.03 = 220.83$.
  - 집단 평균에서의 제곱거리 합: C $53.78 + 0.44 + 44.44 = 98.67$, D $40.11 + 5.44 + 75.11 = 120.67$, 합 $219.33$.
  - 줄어든 양: $220.83 - 219.33 = 1.50$ (검산: $3(27.33-27.83)^2 + 3(28.33-27.83)^2 = 0.75 + 0.75 = 1.50$).
  - 해석: 평균을 둘로 나눠도 거리가 0.7%밖에 줄지 않는다 → "극적인 차이가 없다" → 기각 실패(슬라이드 9의 문장).
    제곱을 쓰는 이유는 `\Cref{def:spread}` 의 분산과 같다고 한 줄로 연결. 정식 검정 통계량은 3.2 (5)의 열린 질문.
- **연습 E4 (본문 예제가 아니라 `pitfall` 안의 연습): 반항적 인간 14%(슬라이드 12).**
  R6~R8의 세 가지(표 읽기 $7/1000$, 구간 경계 모호성, 방향 선택)를 함정으로 보여 준다.

### 4.3 덱 6 → `04-distributions.tex` 채우기

기존 절 라벨(`sec:normal`, `sec:exponential`, `sec:uniform`, `sec:binomial`, `sec:cdf`)은 유지한다.
절 순서는 덱 순서(정규 → 균등 → 지수 → 멱법칙 → 베르누이/이항)와 다르지만 파일 안 재배치는 소유자 결정 없이 하지 않는다. 새 멱법칙 절만 `sec:exponential` 뒤에 추가한다.

1. (장 머리) In brief + 배경 + 왜: 분포 = 측정값의 확률이 퍼진 모양(슬라이드 2~3). 연속/이산 목록.
2. `sec:normal` 채우기(슬라이드 4~10): 중심 = 평균, 폭 = 표준편차. 아기 키 곡선이 더 높은 이유(**플래그:** 슬라이드는 "성인 키의 가능성이 더 많다"고만 쓴다. 원리는 곡선 아래 넓이가 1이므로 폭이 좁으면 높아진다. 이 원리로 풀어 쓴다). 슬라이드 7 "±2 SD에 95%"는 근사(정확히 95.45%, 95%는 ±1.96, `\Cref{sec:ci}` 와 연결). 이동과 척도 변환. 기존 TODO(96.0%, Shapiro 0.00038)는 쓸 때 재확인.
3. `sec:uniform` 채우기(슬라이드 11~14): 주사위 $1/6$. 연속 $[0,5]$ 밀도 $1/5$, $P(1<X<2) = 1/5$, $P(4 < X < 4\tfrac13) = \tfrac13 \cdot \tfrac15 = 1/15$, $P(X=4) = 0$(모두 맞음). 평균 $(a+b)/2$, 표준편차 $(b-a)/\sqrt{12}$(슬라이드 14 그림에서 복원). 기존 `serving_size` 함정 유지.
4. `sec:exponential` 채우기(슬라이드 15~17): 사건 사이 대기 시간. 평균 $1/\lambda$, CDF $1 - e^{-\lambda x}$.
   - 노트북 예제: $\lambda = 1/5 = 0.2$, $P(X<3) = 1 - e^{-0.6} = 0.4512$. **맞음.**
   - 커피숍 예제: 평균 대기 $1/10$ 시간 = 6분. **맞음.** $P(X < 5/60) = 1 - e^{-10 \cdot 5/60} = 1 - e^{-0.8333} = 0.5654$. **슬라이드 값 0.0801은 틀렸다.** $1 - e^{-1/12} = 0.0800$ 과 일치하므로 지수에서 $\lambda$ 를 빠뜨린 것으로 보인다. 상식 검산: 평균 대기가 6분인데 5분 안에 올 확률이 8%일 수 없다.
   - **플래그:** 슬라이드 15의 "$0 < \lambda \le 1$" 은 틀렸다. $\lambda > 0$ 이면 된다. 슬라이드 17 자신이 $\lambda = 10$ 을 쓴다.
5. `subsec:geometric` (신설, `sec:exponential` 안): 기하분포(Geometric Distribution) = 분 단위로 쪼갠 지수분포(슬라이드 18). 웹사이트 첫 방문자, 평균 $\mu = 20$분 → $\lambda = 0.05$/분.
   - 슬라이드: $P(0<x<1) = 0.05$, $P(1<x<2) = 0.95 \cdot 0.05 = 0.0475$, $P(2<x<3) = 0.95^2 \cdot 0.05 = 0.045125$. "첫 1분 놓침, 둘째 1분 놓침"의 곱셈 논리로 설명.
   - 정확한 지수분포 값: $1 - e^{-0.05} = 0.04877$, $e^{-0.05} - e^{-0.10} = 0.04639$, $e^{-0.10} - e^{-0.15} = 0.04413$.
   - **플래그:** 슬라이드 값은 "매분 성공 확률 0.05인 독립 시행"이라는 기하분포 **근사**다(밀도의 시작값 $f(0) = 0.05$ 를 1분 폭에 곱함). 틀린 것이 아니라 근사임을 본문에 밝히고, 두 열을 나란히 놓은 표를 둔다. 무기억성(Memorylessness) 한 문단.
   - 가설검정 장(E2의 $0.4^3$)과 같은 "독립이면 곱한다" 규칙이므로 `\Cref{ch:hypothesis}` 로 앞뒤 연결.
6. `sec:powerlaw` (신설, 슬라이드 19~22): 파레토(Pareto), 80/20 규칙, 지수 $\alpha > 1$, $x_{\min}$, 여집합 CDF(Complementary CDF) 로그-로그 그림. 지수분포와 비교는 기존 그림 `06_06_powerlaw_vs_exponential.png`. 슬라이드 21~22가 밝힌 출처(Mark Newman, Aaron Clauset의 강의 노트)는 "슬라이드가 인용한 자료"로만 적고 bib 항목을 새로 만들지 않는다.
7. `sec:binomial` 채우기(슬라이드 23~29): 베르누이 예제 평균 $0.4 \cdot 0 + 0.6 \cdot 1 = 0.6$, 분산 $0.4(0-0.6)^2 + 0.6(1-0.6)^2 = 0.144 + 0.096 = 0.24 = p(1-p)$(**맞음**). 평균 0.6은 분포가 가질 수 없는 값(슬라이드 24). 이항: 5번 중 꼬리 2번, 특정 순서 하나 $0.5^5 = 1/32$, 순서 무관 $\binom52 / 32 = 10/32 = 0.3125$. 평균 $np$, 분산 $np(1-p)$. 가설검정 장 E1의 이항 계산이 이 절을 가리킨다.
8. `sec:cdf` 채우기: 기존 그림 `06_03_cdf.png`, 두 CDF의 최대 세로 격차 = KS 통계량 $D$. lec07이 이 절을 가리킨다(그림 한 번만).
9. 어떻게 적용: HW1 변수별 분포 판정(기존 TODO 값들). 앞으로: 모수 추정(덱 7), 분포 가정 위의 검정(덱 9).
10. 장 제목(분포, 데이터가 따르는 모양) 사이의 줄표는 기존 텍스트다. 바꿀지는 Q6.

| 가설검정(Hypothesis Testing) | 현장 측량으로 지도 검증 | 지도(귀무가설)가 맞다면 이만큼 어긋난 측량이 나올 법한가를 묻는다. 너무 어긋나면 지도를 고치고(기각), 오차 안이면 고칠 근거가 없을 뿐 지도가 옳다는 증명은 아니다(기각 실패) |

파생 대응(본문에서만, 표에 추가하지 않음): p값 = "지도가 맞을 때 이만큼 어긋날 확률",
$\alpha$ = "지도를 고치기로 **측량 전에** 정한 오차 한계", 확률 계산에 쓰는 분포 = 기존의 투영법.
슬라이드의 자체 장치("$H_0$ 를 터무니없게 만드는가", 금성 외계 생명)는 비유가 아니라 예시이므로
그대로 예시로 쓴다.
